# Teaching content

The files in this folder are the lesson text and the control explanations
shown by the app:

- `lessons/` holds one TOML file per lesson: title, objectives, explanation
  blocks, and exercises with their checks.
- `concepts.toml` holds the caption and panel text for each control.

Numbers the code also uses are written as placeholders such as
`{image_size}`. The app fills them in from the same constants the training
code reads, so the text stays in step with the code.
